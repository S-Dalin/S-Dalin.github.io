Math and code on a hand-written static site

date2026-07-05
tagstutorials
statusreference

You don't need a site generator to publish research notes. This whole site is hand-written HTML; equations come from KaTeX, loaded from a CDN only on pages that need them.

Equations with KaTeX

Add three lines to the page head (see the source of this post), then write LaTeX inline — like the loss $L(\theta) = \frac{1}{n}\sum_{i=1}^{n} \ell(f_\theta(x_i), y_i)$ — or as display math:

$$\nabla_\theta L = \frac{1}{n} \sum_{i=1}^{n} \nabla_\theta \, \ell(f_\theta(x_i), y_i)$$

Code blocks

Plain <pre><code> with a monospace font is honest and fast. If you later want syntax highlighting, add a tiny highlighter (e.g. highlight.js) the same way — one CDN link, only on pages with code:

def log_run(question, setup):
    """Log before you look at the results."""
    with open("log.md", "a") as f:
        f.write(f"## Question\n{question}\n\n## Setup\n{setup}\n")

Why not a framework?

Because the site is the notebook. Every page is one file you can read, diff, and host anywhere static files are served — GitHub Pages, a university server, a Raspberry Pi. No build step, no dependencies, nothing to break while you're busy doing actual research.
